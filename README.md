# מדעי המחשב בספיר – מפת התואר

מפה אינטראקטיבית של תכנית התואר הראשון במדעי המחשב במכללה האקדמית ספיר (תשפ"ז), שהוכנה לוועדת ההוראה של הפקולטה.

**הדף:** https://drkolaman.github.io/sapir-cs-map/

## מה יש בדף
- **המסלול:** כל הקורסים לפי שנה וסמסטר, עם בורר למסלולי ההתמחות (בינה מלאכותית, סייבר, מדעי הנתונים, ניהול מוצר). לחיצה על קורס מציגה את מה שכתוב בסילבוס שלו: נושאים, תוצרי למידה, הרכב הציון והתייחסות ל-AI.
- **השבוע של הסטודנט:** מערכת שעות שבועית לפי מערכת השעות של תשפ"ז.
- **הפערים, מה השתנה בעולם, ושאלות לוועדה.**
- **כיוונים לדיון:** שתי אפשרויות לשיפור התכנית. אלה אפשרויות לדיון, לא החלטה.

## מקורות
- סילבוסי הקורסים (המכלול, מזכירות המחלקה והמרצים). קבצי הסילבוסים עצמם אינם במאגר; במאגר רק הנתונים שחולצו מהם.
- מערכת השעות של תשפ"ז, נכון ל-19.11.2026.
- תכנית הלימודים ומסלולי ההתמחות מאתר המכללה.

הסיווגים (למשל, אילו רכיבי ציון נעשים בפיקוח) נעשו לפי הכתוב בסילבוסים ויש בהם שיקול דעת. תיקונים יתקבלו בברכה.

## מבנה
- `index.html`, `data.json` – הדף.
- `build/` – הסקריפטים (Node.js) והנתונים המעובדים שמהם נבנה `data.json`.
